# filmkit 0.1.0

A preflight-gated production kit for making short films with Higgsfield/Seedance,
running identically under Claude Code and OpenAI Codex.

**One payload, two hosts, four layers, one ritual.** See `ARCHITECTURE.md`.

## Install

```
git clone <your-remote> filmkit
python3 filmkit/bin/filmkit-doctor          # tells you exactly what is not wired yet
```

## Start a film

```
python3 filmkit/bin/filmkit-init ../myfilm
```
